# Release v1.0.0

- Fecha: 2026-11-25
- Tag: `v1.0.0`
- Desde: `v0.2.0`
- Contenido: cierre de la Parte 2 (HU-09 a HU-17), integrado en `main` con el PR #33

## Features

- Terraform con módulos de red, cómputo k3s, registro ECR, almacenamiento S3, observabilidad y
  servidor Jenkins; backend remoto S3 con bloqueo en DynamoDB y ambientes dev, stage, prod y tools (HU-09).
- Kubernetes con los 8 servicios, el cliente web y el middleware, con Kustomize, ConfigMaps, Secrets,
  Ingress Traefik, HPA y un overlay por ambiente (HU-10).
- Pipeline de Jenkins con Terraform, ECR, Trivy, despliegue a dev y stage, aprobación manual para prod,
  tag, release notes y notificación a Discord. Las condiciones de cada stage están en `cgRun()` (HU-11).
- Patrones de diseño: Circuit Breaker, External Configuration y Dead Letter Topic, con pruebas de falla (HU-12).
- Observabilidad con Prometheus, Grafana, Alertmanager, Jaeger y Loki (HU-13).
- Seguridad: escaneo de secretos, dependencias, IaC e imágenes; RBAC; TLS; excepciones con caducidad (HU-14).
- Pruebas avanzadas: escenarios de Locust con objetivos declarados y OWASP ZAP baseline (HU-15).
- Change management: registro de cambios por ambiente y rollback en Kubernetes (HU-16).
- Documentación de cierre, anexo de IAG y diagramas (HU-17).

## Fixes

- Commit-lint: se acortaron 4 mensajes de commit de HU-01 que superaban los 72 caracteres.
- JaCoCo: el plugin de cobertura recibe los directorios de fuentes y ya no reporta archivos no encontrados.
- Excepciones de IaC por regla, con dueño, justificación y vencimiento a 30 días.

## Known issues

- El escaneo de dependencias corre con `SECURITY_GATE=report`: 8 servicios con hallazgos CRITICAL y HIGH.
  El build queda UNSTABLE por esa causa. Es riesgo aceptado temporal, con plan de remediación en el informe.
- El caudal de las pruebas de carga queda por debajo del objetivo a 100 usuarios (techo de capacidad del nodo).
- El pipeline publica en ECR antes de escanear las imágenes con Trivy.
- Las excepciones de seguridad vencen el 22 y el 23 de diciembre de 2026 y deben revisarse antes.
