# Release v0.3.0

- Fecha: 2026-11-21
- Tag: `v0.3.0` (pendiente de publicar desde Jenkins)
- Commit base: `50b343d`
- Desde: `v0.2.0`

## Features

- Terraform con módulos de red, cómputo k3s, registro ECR, almacenamiento S3, observabilidad y
  servidor Jenkins; backend remoto S3 + DynamoDB y ambientes dev/stage/prod/tools (HU-09).
- Kubernetes con los 8 servicios, cliente web, middleware (PostgreSQL, Neo4j, Redis, Kafka,
  ZooKeeper y OpenLDAP), ConfigMaps, Secrets, Ingress, HPA y overlays por ambiente (HU-10).
- Observabilidad con Actuator, Micrometer, Prometheus, Grafana, Alertmanager, Jaeger y Loki;
  dashboards técnicos y de negocio, cinco reglas de alerta y runbook de incidentes (HU-13).
- Seguridad: escaneo de imágenes y dependencias con Trivy, escaneo de secretos, RBAC de Jenkins y
  Kubernetes, terminador TLS y excepciones con caducidad (HU-14).
- Rendimiento y seguridad dinámica: escenarios Locust con objetivos declarados y OWASP ZAP
  baseline con compuerta por severidad (HU-15).
- Registro de cambios ampliado (D-30): `result`, `approved_by`, `approval_ref` e `image_digest`
  en `deploy/record-release.sh` (HU-16).

## Fixes

- Grafana exige `GRAFANA_ADMIN_PASSWORD`; se elimina la contraseña por defecto.
- Validación de la respuesta de identidad y logging estructurado en el login (HU-12).
- Proxy del cliente web sin prefijo duplicado y base nginx 1.30 (HU-02).
- Correcciones de dependencias vulnerables dentro de la misma línea de versión (HU-14).

## Otros

- PRs integrados: #14 (HU-12), #15/#16/#18 (HU-09), #19 (HU-13), #20 (HU-14/15), #21 (HU-10).
- Evidencias de Terraform, Kubernetes, observabilidad, seguridad y rendimiento en `docs/evidencias/`.

## Limitaciones conocidas

- El `Jenkinsfile` todavía no despliega en Kubernetes ni bloquea con Trivy (HU-11 pendiente).
- El rollback en Kubernetes tiene procedimiento implementado; falta ejecutarlo y adjuntar la
  evidencia en `docs/evidencias/hu-16/03-rollback-k8s.txt`.
- Los objetivos de rendimiento no se cumplen a 100 usuarios; el detalle y las correcciones están
  en `docs/evidencias/hu-15/INFORME.md`.
