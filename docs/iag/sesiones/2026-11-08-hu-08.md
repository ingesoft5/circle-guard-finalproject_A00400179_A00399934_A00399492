## Turno 2 · El comando del README falla

### Prompt (literal)

```text
por que pasa esto? puedes arreglarlo?
```

(Se pegó la salida de `./gradlew test coverageSummary` terminando en `Execution failed for task ':tests:integration:test'. > No tests found for given includes`.)

### Respuesta (síntesis)

- **Causa:** el bloque `test` de `build.gradle.kts` excluye `*IntegrationTest` y el módulo `tests/integration` solo
  contiene esas clases; Gradle falla por defecto cuando una tarea se queda sin pruebas. Jenkins no lo mostró porque
  ejecuta las tareas por servicio, no `test` en la raíz.
- **Error de la IA:** el README documentaba ese comando sin haberlo ejecutado desde la raíz.
- **Corrección:** `isFailOnNoMatchingTests = false` en el filtro de `test`. Se comprobó `:tests:integration:test`
  (`BUILD SUCCESSFUL`); la ejecución completa de `test coverageSummary` la repite la persona.
- Los avisos `Broker may not be available (localhost:9092)` de la salida son ruido de los contextos de Spring al cerrarse.

### Decisiones aplicadas

| Decisión | Motivo |
|---|---|
| README en español | El resto de la documentación y el curso están en español; el README anterior mezclaba idiomas |
| Mover (no borrar) la guía larga de HU-01 | El contenido es válido y lo usa la demostración; solo dejaba de ser «general» |
| Diagramas en Mermaid dentro del repo | Se versionan, se revisan en PR y GitHub los dibuja sin herramientas externas |
| No registrar sesiones de HU que la IA no vio | Inventar prompts invalidaría la bitácora; las lagunas se declaran en `IAG_REGISTRO.md` |
