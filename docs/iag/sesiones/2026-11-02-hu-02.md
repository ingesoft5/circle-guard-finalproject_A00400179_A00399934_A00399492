### Explicación del EULA de Nexus

Un **EULA** (*End User License Agreement*) es el contrato de licencia de Sonatype para Nexus
Repository Community Edition. Nexus lo exige antes de habilitar la descarga o la subida de
componentes: no es un error de configuración ni un permiso de Docker. Mientras no se acepte, el
administrador puede entrar a la UI y a la API, pero el repositorio Docker no se crea y `docker
push`/`docker pull` fallan. Aceptarlo es una decisión del equipo porque implica aceptar los
términos legales de Sonatype. HU-01 lo deja explícitamente en `NEXUS_ACCEPT_EULA=false` y el
script reporta `PLAN`; por eso HU-02 usa un registro OCI equivalente para la evidencia y deja
Nexus preparado para cuando se acepte.
