## Turno 3 · Ejecución real, incidencias y rollback

### Prompt (literal)

```text
No veo que continue
```

### Respuesta (síntesis)

- El build #18 estaba detenido porque el nodo Built-In de Jenkins quedó `offline`: el monitor de
  disco conservaba una lectura vieja (120 MB), aunque `/var/jenkins_home` tenía 6.7 GB libres.
- Se reinició Jenkins, se puso el nodo online y el build se reanudó.
- El build #18 terminó `UNSTABLE` porque el reinicio interrumpió la tarea durable de
  `Unit tests and coverage` (JENKINS-48300); no fue un test fallido. El CD continuó y desplegó
  prod `0.2.0`.
- Se detectó que `tag-release.sh` no reconocía `PUSH_TAG=true` (esperaba `1`) y que
  `github-release.sh` no enviaba `target_commitish`; el tag quedó local y el release apuntó al
  branch por defecto. Se corrigieron ambos scripts y se recreó el tag/release en `59cec5c`.
- Se ejecutaron los rollbacks reales: dev `0.2.0 → 0.1.0` (build #19) y prod `0.2.0 → 0.1.0`
  (build #21), ambos `SUCCESS` y con 15 servicios healthy.
