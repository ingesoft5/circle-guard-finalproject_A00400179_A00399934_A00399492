## Ajuste de clasificación

El reporte HTML de HU-04
(`docs/evidencias/hu-04/02-informe-integracion/cross-service/classes/...html`) contiene el
password efímero que Spring Boot genera al arrancar una prueba (`Using generated security
password: ...`). No es una credencial real.

Para no ocultar el hallazgo, `infra/scan-secrets.sh` lo sigue listando, pero clasifica los HTML
bajo `docs/evidencias/` como `PRUEBA` en lugar de `ACTIVO`. No se modificó HU-04 ni el contenido del
reporte; el cambio está en la clasificación del escáner.

## Reportes

se versionan. Este archivo es el resumen reproducible para el PR.
